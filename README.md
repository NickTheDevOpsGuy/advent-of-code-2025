## ▶️ How to Run Any Day

1. Enter the day folder:

```bash
cd day01
```

2. Ensure **input.txt** contains your puzzle input.

3. Run the Python solution:

```bash
python3 solution.py
```

4. Celebrate when the answers print correctly 🎉

---

## 🧪 Running Built‑In Tests (Optional)

Some day's solutions (such as Day 1) include a small internal test suite.

To enable tests:

1. Open `solution.py`  
2. Scroll to the bottom and locate:

```python
RUN_TESTS = False
```

3. Switch it to:

```python
RUN_TESTS = True
```

4. Run:

```bash
python3 solution.py
```

You’ll see something like:

```
Running tests...
All tests passed!
```

Switch back to normal puzzle mode afterward:

```python
RUN_TESTS = False
```

## 🎁 Tips for Future Nick (and anyone else)

- Test logic using the example input before the full puzzle  
- Don’t prematurely optimize; correctness first  
- When stuck:
  - print intermediate values  
  - reduce input  
  - walk through logic manually  
- Keep commits small and meaningful  
- Have fun — it’s Advent, not production
