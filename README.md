▶️ How to Run Any Day

1.	Enter the day folder:

```bash
cd day01
```

2. Make sure *input.txt* contains your puzzle input.
3. Run the Python solution:

```bash
python solution.py
```

4.  Celebrate when it outputs the correct answer.

---

🎁 Tips for Future Nick (and anyone else using this repo)

• Always test your logic with the example input before running the full puzzle.
• Don’t over-optimize — correctness first, speed later.
• When stuck:
    • print intermediate values
    • reduce the input
    • walk through the logic with pen & paper
